# Icons

`icon-16/48/128.png` are the active set, referenced from `manifest.json`.

## Alternatives

`alt/accent-*.png` — the same mark in the extension's accent colour (#67c1f5),
which matches the overlay and options page.

`alt/scale-*.png` — the original mark: a measurement scale with end ticks and
an off-centre pointer. It carries no third-party branding, and it depicts the
product's actual thesis, that every figure here is a range with a reading
somewhere inside it.

Swap by copying a variant over `icon-16/48/128.png`. No manifest change needed.

## Trademark

The active set is derived from the Steam logo, which is a registered trademark
of Valve Corporation. This project is not affiliated with or endorsed by Valve.
Chrome Web Store policy restricts using another party's branding in a way that
suggests affiliation, so this choice carries a real review risk. `alt/scale-*`
exists as the safe fallback.
